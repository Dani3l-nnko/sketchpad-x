# The Quiet Signal

A small, standalone three-page portfolio prototype for Daniel. Open `index.html` in a browser to start; the navigation connects the home, about, and observatory concept pages. No build tools or external assets are required.

## Pages

- `index.html` — portfolio landing page and IT focus areas
- `about.html` — profile framing and working approach
- `observatory.html` — interactive, illustrative observability case-study layout

The observatory diagram uses fictional labels and sample statuses to demonstrate the interaction only. Replace it with details, screenshots, and outcomes from a real project before publishing. No work history, contact details, or project results have been invented.

The theme control switches between dark and light palettes and remembers the selection in the browser. Select nodes in the observatory diagram to update the sample readout.
